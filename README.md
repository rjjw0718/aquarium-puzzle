# 🐠 아쿠아리움 (Aquarium) 퍼즐 게임

> **가야중학교 1학년 수학 (주진우 선생님)** 학습지를 기반으로 제작된 웹 기반 두뇌 논리 퍼즐 게임입니다.  
> 아름다운 수족관 일러스트와 함께 19개의 단계별 퍼즐 및 연습 문제를 웹 브라우저에서 바로 즐길 수 있습니다.

---

## 🎮 게임 특징 및 기능

1. **환상적인 아쿠아리움 비주얼 & 배경음악(BGM)**
   - 첨부된 아름다운 피아노 배경음악(`bgm.mp3`)이 게임 내내 감미롭게 무한 반복 재생됩니다.
   - 상단 헤더의 `🎵` 버튼으로 언제든 배경음악을 켜고 끌 수 있습니다.
   - 부드러운 수면 빛내림(Light rays), 떠오르는 물방울(Bubbles), 유영하는 열대어 실루엣 애니메이션 적용

2. **직관적인 조작 체계 (마우스 좌/우 클릭)**
   - **마우스 왼쪽 버튼 (좌클릭)**: 수족관에 **물 채우기 (💧)** (다시 누르면 취소)
   - **마우스 오른쪽 버튼 (우클릭)**: 물이 채워지지 않는 칸에 **X 표시 (❌)**
   - 마우스 드래그를 통한 연속 입력 지원
   - 모바일/태블릿 터치 사용자를 위한 상단 [물 모드 / X 모드] 토글 지원

3. **단계별 순차 해금 시스템 (잠금 기능)**
   - **1단계를 통과해야만 2단계가 열립니다.**
   - 아직 통과하지 못한 단계는 자물쇠(🔒)로 잠겨 있어 선택할 수 없습니다.
   - 진행 상황은 브라우저에 자동 저장되어 새로고침 후에도 유지됩니다.

4. **학습지 규칙 100% 충실 반영**
   - 1. 게임판은 정사각형 격자이며, 여러 개의 ‘수족관’(굵은 선)으로 나뉩니다.
   - 2. 물은 중력에 의해 바닥부터 차오릅니다.
   - 3. 각 수족관의 수위는 왼쪽 끝부터 오른쪽 끝까지 동일합니다.
   - 4. 격자 밖 힌트 숫자는 해당 행/열에서 물로 채워야 하는 칸 수를 나타냅니다.

5. **스마트한 정답 확인 시스템**
   - 답을 미리 공개하지 않고, 플레이어가 입력한 물(💧)의 자리와 개수만 정확히 판정합니다.
   - X 표시는 오직 플레이어의 편의를 위한 보조 마크이므로 채점에 영향을 주지 않습니다.
   - 틀렸을 경우: **"다시 해보세요."** 알림과 함께 현재 입력 상태를 그대로 유지하여 즉시 수정 가능합니다.
   - 맞았을 경우: **"정답입니다! 🎉"** 축하 팡파르 & 컨페티 효과와 함께 다음 퍼즐이 해금됩니다.

6. **총 19개의 본 퍼즐 + 연습 문제 수록**
   - **연습 문제**: 6×6 튜토리얼 (규칙 설명 화면에서 시각적 비교 뷰어 제공)
   - **1단계 ~ 16단계**: 6×6 격자 퍼즐
   - **17단계 ~ 19단계**: 10×10 마스터 퍼즐
   - 19개의 모든 퍼즐을 완주하면 최종 엔딩 축하 화면이 나타납니다.

## 🚀 깃허브(GitHub)에 업로드 및 GitHub Pages로 무료 배포하는 방법

이 프로젝트는 순수 **HTML, CSS, JavaScript**로 제작되어 별도의 서버 설치나 빌드 과정 없이, GitHub 저장소에 올리기만 하면 누구나 무료로 웹 게임 사이트를 운영할 수 있습니다.

### GitHub 웹사이트에서 올리는 방법

1. [GitHub](https://github.com)에 로그인한 뒤 저장소 메인 화면으로 이동합니다.
2. 우측 상단의 **[Add file ▼]** ➔ **[Upload files]**를 클릭합니다.
3. `aquarium-puzzle` 폴더 안의 모든 파일(`index.html`, `style.css`, `puzzles.js`, `game.js`, `bgm.mp3`, `README.md`)을 마우스로 드래그하여 업로드합니다.
4. 화면 하단의 **Commit changes** 초록색 버튼을 누르면 업로드가 완료됩니다!
   *(기존 파일이 있더라도 자동으로 최신 파일로 덮어씌워집니다.)*

### 🌐 GitHub Pages 설정 확인

1. 저장소 상단 **Settings** ➔ 좌측 **Pages** 메뉴 선택
2. **Branch**가 `main` (또는 `master`), 폴더가 `/(root)`로 되어 있는지 확인하고 **Save** 클릭
3. 1~2분 뒤 생성되는 `https://<당신의아이디>.github.io/저장소이름/` 링크로 접속하면 어디서든 플레이할 수 있습니다!
